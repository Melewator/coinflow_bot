# 🪙 Coin Flow 

**Coin Flow** is a streamlined personal finance tracker built directly into Telegram. Designed for speed and reliability, it allows users to log daily expenses, monitor their budget, and interact with a clean interface without leaving the messenger. 

### ✨ Key Features
* **Telegram Mini App UI:** Offers a responsive, modern interface built right into Telegram for seamless budget management.
* **Smart Expense Tracking:** Quick transaction logging with manual confirmation steps to ensure accuracy before data is saved.
* **Optimized Currency Handling:** Tracks personal finances efficiently with USD set as the default base currency.
* **High Reliability:** Engineered with intelligent rate-limiting delays and fallback mechanisms to ensure the bot remains responsive even during periods of high network demand.
